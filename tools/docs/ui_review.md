## 3. Правила, которые теперь соблюдаются везде

1. **Порядок кнопок**: слева «Отмена/Назад», справа действие. Действие
   никогда не в фокусе по умолчанию (подпись, удаление).
2. **Три класса подтверждения**:
   - обычное — одна кнопка (`mw_ui_confirm`);
   - потеря средств при неверном решении — два подтверждения подряд
     (пустой passphrase);
   - необратимое уничтожение данных или прожиг — число на экране
     (`mw_ui_confirm_code`).
3. **Заголовок = что вводим**. Клавиатура получает `title`, строка ввода
   подписывается «Ввод»/«Начало слова», не «Префикс».
4. **Один экран поверх корня**. Диалоги — оверлеи, страницы не вкладываются
   (правило из `lvgl_port.cpp` сохранено, новые экраны ему следуют).
5. **Секреты не в логах**. `log.h` формулирует запрет; view key показывается
   только через `mw_ui_text_view` и нигде не логируется.
6. **Все строки в `i18n.c`**, RU и EN парами. Новые: `XSTR_KB_*`, `XSTR_CODE_*`,
   `XSTR_PW_*`, `XSTR_WL_*`, `XSTR_VIEWKEY_*`, `XSTR_DEBUG_LOG`, `XSTR_ON/OFF`.

## 4. Что осталось несистематизированным

- Экран прогресса без отмены везде, кроме ожидания файла по USB-линку.
  Подпись Bulletproof+ на устройстве может идти долго; кнопка «Отмена»
  там потребует поддержки отмены в `mw_sign_transaction`.
- Кириллический шрифт по-прежнему не собран, поэтому стоковая сборка
  стартует по-английски.
- Экран «Об устройстве» — просто текст; сюда логично вынести состояние
  пароля, eFuse и USB-транспортов.
- Игра-маскировка «Минёр» (ТЗ 2.0 §3.7) не начата; при её добавлении корневой
  экран станет игрой, а меню кошелька — вторым уровнем.
